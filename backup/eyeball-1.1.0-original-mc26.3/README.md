# Backup: original EyeBall Mod 1.1.0 (Minecraft 26.3)

This is the untouched release jar of the original **EyeBall Mod 1.1.0** for Minecraft 26.3, kept
as a backup before the project was renamed to **Googly Goobers**.

- It is **not** part of the Googly Goobers release and must not be uploaded to Modrinth
  (it still contains the removed Elmo-style transformation).
- Checksum: `eyeball-1.1.0.jar.sha256` (verify with `sha256sum -c eyeball-1.1.0.jar.sha256`).
- Every other original EyeBall jar (1.0.0 for 26.3, 1.0.0 and 1.1.0 for 26.2), with the original
  sources, is preserved in this repository's git history at commit `e7e5479`
  ("Release EyeBall Mod 1.1.0 for Minecraft 26.3 and 26.2"):
  `git show e7e5479 --stat`, `git checkout e7e5479 -- dist/`.
